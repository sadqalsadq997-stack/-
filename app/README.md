# فلسي — تطبيق نقطة البيع والمحاسبة (Flutter)

تطبيق واحد لـ **أندرويد وآيفون/آيباد وويندوز**، ومربوط بنفس نظام فلسي (Supabase عبر `felsy.org/api/db`).

## المزايا
- **الدخول:** بالبريد وكلمة المرور (10 محاولات لكل جهاز)، ثم رمز PIN للمستخدم. يقفل تلقائياً بعد 30 دقيقة.
- **نقطة البيع:**
  - تشتغل **بدون إنترنت**: الفاتورة تنحفظ بالجهاز برقم خاص بالجهاز، وتطبع برمز QR، وترتفع للسيرفر والهيئة تلقائياً لما يرجع الاتصال.
  - باركود، خصم، ولاء، وفاتورة شركات B2B.
- **الطباعة:**
  - طابعة حرارية عبر الشبكة (ESC/POS على المنفذ 9100) بعربي سليم ودرج نقود.
  - طابعة النظام: AirPrint، أندرويد، أو ويندوز مباشرة.
  - PDF.
- **الأقسام:** لوحة التحكم، الفواتير والمرتجعات، المنتجات، المخزون، العملاء، المشتريات، المصروفات.
- **المحاسبة:** الإقرار الضريبي بخانات الهيئة (PDF)، قائمة الدخل، ميزان المراجعة. آخر نسخة تبقى متاحة بدون إنترنت.
- **الفوترة الإلكترونية:** الربط برمز OTP، اختبار على بيئة الهيئة، ومتابعة وإعادة إرسال.
- **إشعارات مهمة فقط:**
  - تطلع من الجهاز نفسه بدون خدمة خارجية.
  - حدها 6 في اليوم، مع ساعات هدوء، وتقدر تتحكم بكل نوع.
- **الخصوصية:**
  - ما فيه تتبّع ولا إعلانات ولا تحليلات.
  - أسرار الجلسة في الخزنة الآمنة للجهاز.
  - بيانات المنشأة تنمسح من الجهاز عند الخروج، إلا الفواتير اللي ما انرفعت.
  - حذف الحساب متاح من داخل التطبيق.

## البناء
البناء يصير على GitHub Actions (`.github/workflows/app.yml`)، والتفاصيل في `docs/PUBLISHING.md`.

محلياً (إذا عندك Flutter 3.47):
```bash
cd app
flutter pub get
flutter test
flutter run                      # جوال/محاكي متصل
flutter build apk --release      # أندرويد
flutter build windows --release  # ويندوز
```

## الهيكل
```
lib/core       الاتصال، التسعير والضريبة (مطابق للسيرفر)، QR الهيئة، PIN، التخزين
lib/services   الجلسة، الجهاز، الكتالوج، المبيعات (طابور بدون إنترنت)، الاتصال، التنبيهات
lib/printing   رسم الإيصال (عربي) + ESC/POS + PDF
lib/features   الشاشات
```
